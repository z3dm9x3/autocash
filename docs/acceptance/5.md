# Этап 5 «Веб-админка» — критерии приёмки и тесты

Запуск: `timeout 1200 python -m pytest -q tests/acceptance/test_web_admin.py`.
Решения: `docs/decisions.md` D-5-1…D-5-6.

| № | Критерий | Тест |
|---|---|---|
| 1 | Изменение через админку равнозначно правке файла: тот же результат, та же проверка, та же версия в журнале | `test_change_through_admin_equals_file_edit`: роли кассы и рубильник модуля из админки дают ту же версию, что и такая же ручная правка файла; файл на диске содержит изменение; версия есть в `config_versions`, автор — в `config_changes` |
| 2 | Невалидное изменение отклоняется с понятной ошибкой, действующая конфигурация не меняется | `test_invalid_change_is_refused_with_a_clear_error`: дубль источника, битый YAML, неизвестный оператор условия, изменение со старой страницы — ошибка на странице, версия и байты файла прежние, попытки записаны в журнал |
| 3 | Трассы и пул в интерфейсе совпадают с выводом `/trace` и `/accounts` | `test_trace_and_pool_pages_match_the_commands` |
| — | Доступ только admin/dev, CSRF, выход | `test_access_only_for_admin_roles_and_with_csrf` |
| — | Отправка из админки — только через очередь исходящих | `test_send_goes_through_the_outbound_queue` |

## Как включить

1. В конфигурации: `web.enabled: true` (по умолчанию слушает `127.0.0.1:8088`).
2. Пароль пользователю с ролью admin или dev: `python -m autocash.cli.webuser set <Telegram ID>`.
3. Доступ с рабочего компьютера: `ssh -L 8088:127.0.0.1:8088 <сервер>`, затем http://127.0.0.1:8088.

## Чего тесты не проверяют

- Вёрстку и удобство страниц в браузере (проверяются вручную).
- git-коммит изменений конфигурации (в тестах выключен: каталог тестов не в репозитории).
