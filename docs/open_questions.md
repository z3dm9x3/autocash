Каждое значение — параметр конфига; в коде помечено `# OPEN-QUESTION: <требование>`. Дефолт действует, пока заказчик не ответит.

| Темп отправки | ФТ-9.7 | `output.pacing` | бот: 1 с в чат, 20 в минуту в группу, 0,04 с всего; пользовательский аккаунт: 3 с в чат, 3 с всего, 10 в минуту в группу. Для пользовательских — оценка (D-1b-4) |
| Замедление после FloodWait | ФТ-10.3 | `pool.flood_slowdown`, `pool.flood_recovery_s` | темп делится на 2, возврат через 600 с |
| Подстраховочный опрос | ФТ-2.5 | `poll.chats_per_account`, `poll.silence_norm_s` | 10 чатов на аккаунт; «тишина дольше нормы» — 600 с |
| Политика личных диалогов | п. 1.3, ФТ-2.4 | `defaults.private_chat_policy`, `defaults.private_template` | `full`, без шаблона (D-1b-6) |

Без ответа заказчика остаются:

- **Состав пула: в каких кассах состоит каждый аккаунт (ФТ-1.5).** Система узнаёт это сама из списка диалогов; вопрос нужен, чтобы понять, достижимо ли покрытие 2.
- **Кассы — супергруппы или обычные группы (ФТ-2.11).** Определяется по типу чата в обновлении, настройка не нужна. Но подстраховочный опрос и догон работают только для супергрупп (D-1b-10): если кассы — обычные группы, для них этой страховки нет.
- **Когда считать PEER_FLOOD снятым.** Сейчас только вручную (D-1b-9).
