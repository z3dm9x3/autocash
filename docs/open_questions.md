# Открытые вопросы ТЗ (раздел 8) и действующие дефолты

Каждое значение — параметр конфига; в коде помечено `# OPEN-QUESTION: <требование>`. Дефолт действует, пока заказчик не ответит.

## Уже в конфиге (этап 1a)

| Вопрос | Требование | Параметр | Дефолт |
|---|---|---|---|
| Резервный срок хранения записей в SQLite | ФТ-4.3 | `buffer.retention_hours` | 72 ч |
| Срок хранения текста по типам сообщений | ФТ-5.3 | `retention.default_text_ttl_days`, в правиле — `text_ttl_days` | 90 дней |
| Срок хранения детальных трасс | ФТ-11.11 | `retention.trace_days` | 30 дней (очистка — этап 1c) |
| Сроки жизни исходящих по типам | ФТ-9.6 | `output.ttl_s` | ответ на команду 300 с, ответ клиенту 1800 с, уведомление 3600 с, массовое 86400 с |
| Нормативы времени этапов | ФТ-11.7 | `stage_norms_s` | буфер 0,2 с; PostgreSQL 0,5 с; сортировка 0,7 с; очередь модуля 1 с; обработка 10 с (используются с этапа 1c) |
| Политика приёма для нового чата без роли | ФТ-2.4 | `defaults.unknown_chat_policy` | `meta` |
| Часовой пояс границ суток | НФТ-19 | `report_timezone` | `Europe/Moscow` |
