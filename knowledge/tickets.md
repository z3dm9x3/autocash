# Тикеты — C-ticket: тип обращения игрока D, W, Q

Игрок пишет в личные сообщения аккаунту поддержки. Ticket System (TS) открывает тикет на первое сообщение и
определяет его тип:

- **D** — депозит: игрок пополнил счёт, деньги не зачислились;
- **W** — вывод: игрок вывел деньги, они не пришли;
- **Q** — тип неизвестен: приветствие, невнятный вопрос, признаки и депозита, и вывода.

Задача C-ticket — только определить тип. Дальнейшую работу с тикетом ведут другие протоколы.

## §1. Порядок

Тип ищется в течение первой минуты от первого сообщения тикета. Каждое сообщение проверяется сразу:

1. **Код вывода.** В сообщении есть кандидат в код (`withdrawals.md` §5) → TS ищет его в базе
   кодов вывода. Найден → **W**.
2. **Триггеры.** Код не найден или его нет → поиск слов-триггеров:
   - только признаки депозита → **D**;
   - только признаки вывода → **W**;
   - признаки D и W в одном сообщении → **Q**, однозначно.
   - ничего нет → следующее сообщение.
3. За минуту ни кода из базы, ни триггера → **Q**.

Тип ставится один раз. После этого признаки больше не ищутся, тип не меняется.

База кодов вывода пока не подключена: сейчас код никогда не «найден», и тип определяют триггеры.

## §2. Признаки депозита (D)

Слово в любой форме, с опечатками:

| признак | примеры |
|---|---|
| пополнение | пополнил, пополнила, пополнение, пополнить, попалнил |
| депозит | депозит, депозита, дипозит, депазит |
| деп | деп, депа, депнул, задепал, дэп (целым словом: «депутат» — нет) |
| закинул | закинул, закинула, закидывал (без слова «код») |
| на игру | на игру, на игровой |
| чек | чек, чека, чеки, квитанция |
| оплатил | оплатил, оплатила, оплачено |
| перевёл | перевёл, перевела, перевели |
| платёж | платёж, платежа |
| PDF | документ PDF |
| пересланное сообщение бота депозита | «Переведите точную сумму», «Заявка #… создана», «EPOS ID», «Реквизиты для оплаты», «Метод пополнения», «Ожидание реквизитов», «…Время модерации может составлять до 30 минут» |

## §3. Признаки вывода (W)

| признак | примеры |
|---|---|
| вывод | вывод, вывел, вывести, выведу |
| выплата | выплата, выплаты |
| выигрыш | выигрыш, выигрыша |
| карта | карта, карту, карты, картой, карточка (не «картинка») |
| снял | снял, снять, снятие (не «снял видео», не «с меня сняли») |
| пересланное сообщение бота вывода | «Ваша заявка отправлена на модерацию» (короткое), «Введите название вашего банка» |
| код вывода | только если найден в базе кодов вывода |

## §4. Не признаки

Встречаются и у депозитов, и у выводов: «завис», «сутки», «24/48 часов», «деньги не пришли», «где деньги»,
«зачисление», «реквизиты», «модерация» в словах игрока.

## §5. Примеры

| сообщения игрока | тип |
|---|---|
| «Здравствуйте» → «не пришёл деп» | D (по второму сообщению) |
| PDF без текста | D |
| «Вывод не пришёл за 24 часа» | W |
| «мне на карту не пришли деньги» | W |
| «пополнял через бота, как вывести деньги?» | Q (D и W в одном сообщении) |
| «Пополняла баланс по номеру карты» | Q (D и W в одном сообщении) |
| «Здравствуйте» → минута тишины | Q |
| «tfVQ» | W, если код есть в базе; иначе — Q через минуту |
