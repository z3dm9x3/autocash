# Выводы — код вывода

Код вывода — 4-символьный код заявки на вывод. Игрок получает его на сайте или в приложении (раздел «Запросы на
вывод» → «Получить код») и отправляет боту кассы. В WW-группе кассы бот публикует карточку `[ВЫВОД]` со строкой
`Код:`. Игроки присылают этот код в поддержку, когда спрашивают о выводе.

## §1. Карточка `[ВЫВОД]`

```
[ВЫВОД]
Пользователь: @<username> ID: <TGID>

Платформа: 65
Номер счёта: <MelID>
Код: 9Bz7
Сумма вывода: 2 000
Метод оплаты: СБП Monetra ❤️ 1 000 - 500 000
Реквизиты: 79XXXXXXXXX
Банк: Яндексбанк

✅ Успех: Операция выполнена успешно
```

Строка `Код:` — единственное место, где код записан достоверно.

## §2. Формат кода

По 600 случайным строкам `Код:` из карточек `[ВЫВОД]` всех WW-групп Cash Monitor Dev (PG 5433, снято 2026-11-20):

- **Всегда ровно 4 символа:** латинские буквы и цифры. Регистр значим: `tfVQ` ≠ `TFVQ`.
- **Алфавит генератора:** цифры `1`–`9` и латинские буквы, кроме `0`, `O`, `I`, `l` и заглавной `Z` — их нет ни в одном
  из 573 кодов.
- **Состав:**

  | признак | доля |
  |---|---|
  | смешанный регистр (`hA3s`, `EyMg`) | 81 % |
  | только буквы (`HCXY`, `jdaa`, `Rcrw`) | 51 % |
  | одна цифра (`9Bz7`, `cLh8`) | 38 % |
  | две цифры (`u62P`, `91B4`) | 10,5 % |
  | три цифры (`R851`) | 0,9 % |
  | только заглавные / только строчные буквы | 9 % / 10 % |

- 4 цифры подряд не встречаются; 3 цифры подряд — у 0,5 % кодов (`449x`, `R851`, `139D`).
- **Ошибки игроков:** 27 из 600 значений `Код:` (4,5 %) — 6–7 цифр (`572143`, `7277546`): это код из SMS, а не код
  вывода.

## §3. Как Autocash ищет код в сообщении игрока

Кандидат в код вывода — отдельное слово (не часть ссылки, `@username`, `#тега`, имени файла):

- ровно 4 символа `A–Z a–z 0–9`;
- хотя бы одна латинская буква (только буквы — можно: `yzdm`);
- нет трёх цифр подряд (`998p` — не код);
- не слово из списка исключений: `EPOS`, `Read`, `Cash`, `Fast`, `RAMZ`, `USER`, `Test`, `1WIN`, `Ozon`, `Bank`,
  `RWMG` (из шаблона бота депозита), английские слова (`made`, `with`, `have` …), азербайджанские и узбекские слова
  (`saat`, `geri`, `amma` …). Полный список — `modules.ticket_system.config.code_exclusions`.

Кандидат — ещё не код. Тикет становится **W**, только если код найден в базе кодов вывода (`tickets.md`).

Код из сообщений игроков, как он выглядит:

```
tfVQ
1 758 918 313 / rywT
Вывод с аккаунта 113 465 895 tfVQ
id №<TGID> код вывода на 80 000 CxQz через примьер
Запрос номер <номер> / ID <TGID> / Код 2d6N
так и не поступил. wp8s
```
