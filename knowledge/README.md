# knowledge/ — база знаний Autocash

Предметные знания о сообщениях касс: как они выглядят, что означают, как связаны. Для людей и агентов.
Код и конфиг описывают, *как* Autocash обрабатывает сообщения; здесь описано, *что* приходит из Telegram.

Одна тема — один файл, внутри — логические разделы с номерами (`§N`).

| Файл | О чём |
|---|---|
| `deposits.md` | Заявки на депозит. Часть I — общее (опознание, поля, этапы, отмены, суммы, перенаправление, связывание, команды методов, ловушки разбора). Часть II — методы: Треугольник, Предустановленная сумма, Top Pay, Полигон, NSPK. Часть III — источники данных (PG 5433 монитора, таблицы Autocash). |
| `withdrawals.md` | Заявки на вывод. Часть I — общее (опознание, поля карточки `[ВЫВОД]`, цикл и кнопки, итоги проверки кода с кодами ответа платформы, **код вывода** — формат по 6 419 принятым кодам, неуникальность, проверка, поиск в сообщении игрока; выплата кассой по инструкции для кассиров, сообщения поддержки, связывание, ловушки). Часть II — WW-группы касс. Часть III — источники данных. |
| `cashiers.md` | Кассы и кассиры. Часть I — правила (касса = своя WW-группа, название по группе, кто кассир, номера методов, типы реквизитов). Часть II — справочник касс: DOP/WW-группы, Платформа, кассиры (TGID, username), номера методов, реквизиты; особенности касс, группы без WW, Полигон. Часть III — служебные аккаунты, нагрузка и часы работы, источники. |
| `tickets.md` | Тикеты игроков: C-ticket — тип обращения D / W / Q, порядок проверки, признаки депозита и вывода, примеры. |

## Соглашения

- Термины — как в `AGENTS.md`: **TGID** — Telegram user id (в заявке поле `ID`), **MelID** — номер игрового счёта (в заявке поле `Номер счёта`), **Deposit ID** — ключ заявки, общий для всех касс.
- Типы сообщений — имена сортировщика Autocash: `deposit.request`, `deposit.requisites`, `deposit.sent`, `deposit.receipt`, `method.on/off/limits`.
- Этапы заявки — значения `deposits.stage`: `created → requisites → sent → receipt → final | cancelled`.
- Примеры текстов — реальные форматы с обезличенными значениями (`<TGID>`, `79XXXXXXXXX`, `<Deposit ID>`). Строки, пробелы и эмодзи сохранены точно.
- Источник наблюдений: последние 200 сообщений групп Blade Dop, SprintPay DOP, Top pay #1 DOP, Полигон DOP, Hermes Cash DOP и сводка заголовков/методов/причин отмен по всем DOP-группам за 14 дней (снято 2026-11-20).
- Пометка **[трактовка]** — смысл выведен из наблюдений и не подтверждён владельцем касс.

## Как пополнять

- Новый метод депозита → новый раздел в части II `deposits.md` по образцу (признаки → этапы → примеры → особенности) и строка в «Содержании» в начале файла.
- Правило, верное для всех методов, — только в части I; в разделах методов не повторять, ссылаться `§N`.
- Новая тема (выводы, тикеты и т. п.) → новый файл `<тема>.md` с той же структурой и строка в таблицу выше.
